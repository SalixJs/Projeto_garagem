# Garagem

O Garagem é um projeto de aplicativo gratuito para quem quer modificar o carro no Brasil. A proposta é reunir orientações sobre regularização de modificações veiculares e facilitar a busca por oficinas especializadas, com uma experiência pensada para celular.

## O que o projeto pretende resolver

Antes de fazer uma modificação, pode ser difícil saber por onde começar, quais documentos consultar e que tipo de oficina procurar. O Garagem pretende reunir essas informações em um só lugar, com linguagem acessível, fontes identificadas e datas de atualização.

## Escopo da primeira versão do aplicativo

- **Guias de regularização.** Consultar orientações por tipo de modificação, com etapas, documentos, fontes e data de atualização.
- **Busca de oficinas.** Encontrar oficinas por região, distância e serviço. Consultar especialidades, endereço e canais de contato direto.
- **Preços quando disponíveis.** Exibir valores ou faixas informados pela oficina, com data de atualização.
- **Manutenção do catálogo.** Permitir que responsáveis autorizados revisem guias e mantenham o diretório de oficinas atualizado.

## Andamento do projeto

O repositório reúne o escopo, os requisitos, os diagramas e o esquema de dados. A tag [v0.1.0](../../tree/v0.1.0) registra a primeira publicação desses materiais. Os recursos descritos acima fazem parte do planejamento do aplicativo.

A formação do diretório inicial de oficinas ainda precisa ser validada. Guias técnicos sobre peças e melhorias, avaliações e cadastro autônomo de oficinas estão previstos para uma fase posterior.
