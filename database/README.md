# Banco atual

`garagem.sql` é uma cópia do SQL completo publicado no [garagem_prototipo](https://github.com/SalixJs/garagem_prototipo/blob/main/database/01_banco_principal.sql): 18 tabelas, 11 guias no schema `garagem2`.

Consulte as [instruções para MySQL Workbench](https://github.com/SalixJs/garagem_prototipo/tree/main/database). Os arquivos são idênticos nesta atualização; o repositório de implementação é a referência para alterações futuras.

`historico/garagem.sql` registra a primeira modelagem acadêmica, com nomes em português e banco `garagem`. Ele não deve ser usado para instalar a aplicação atual.
